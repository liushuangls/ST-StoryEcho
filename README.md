# ST-StoryEcho

StoryEcho 是一个面向 SillyTavern 长篇角色扮演聊天的上下文管理扩展。它只保留一项产品功能：

> 启用 StoryEcho 上下文管理

启用后，插件用“近期原文 + 最近阶段总结 + 全局剧情骨架”替代无限增长的完整聊天历史。插件不抽取剧情记忆，不生成 Embedding，不访问 Vector Storage，也不执行动态召回。

## 工作方式

设：

- `W`：始终保留的最近原文窗口，默认 10 轮；
- `N`：每条阶段总结覆盖的完整轮数，默认 10 轮；
- `S`：每次请求直接携带的最近阶段总结数，默认 4 条。

每次正常生成前，StoryEcho 只会裁剪已经被阶段总结完整覆盖的原文。后台尚未追上、总结失败或来源发生变化时，对应原文继续保留，因此不会用缺失的总结换掉真实聊天内容。

窗口外历史累计满 `N` 个完整“用户 + AI”轮次后生成一条独立阶段总结。从第二条开始，会附带上一条总结末尾最多 5000 字符，帮助衔接时间线和未决事项。

全局骨架的首次生成规则是：当有效阶段总结数量第一次达到 `S + 1` 时，最老的一条总结进入归档区，插件从旧到新读取当时全部有效阶段总结并生成骨架。之后每有新的总结进入归档区，就用“旧骨架 + 新归档总结”做一次增量更新。最近 `S` 条总结仍直接随角色请求发送。

阶段总结和骨架可以选择参考：

- 全部蓝灯常驻世界书条目，合计最多 20000 字符；
- 由当前批次原文直接命中的绿灯条目，默认最多 5 条、合计最多 10000 字符。

世界书只作为设定背景，不证明剧情已经发生。

## 请求结构

StoryEcho 在请求期临时插入两个中立的 system/narrator 块，不写入聊天记录：

```text
<story_echo_skeleton>
更早历史形成的全局剧情骨架
</story_echo_skeleton>

<story_echo_summary>
最近阶段总结
</story_echo_summary>

近期原文
当前用户输入
```

发生冲突时使用以下时间优先级：

```text
当前用户输入 > 近期原文 / MVU 变量 > 最近阶段总结 > 全局剧情骨架
```

## 设置

- 启用 StoryEcho 上下文管理；
- 最近原文窗口及单位；
- 阶段总结批次 `N`；
- 随请求保留的总结数 `S`；
- 阶段总结和骨架输出 Token 上限；
- 世界书参考开关与绿灯条目上限；
- SillyTavern 主连接或自定义 OpenAI 兼容 LLM；
- 调试记录。

设置页还提供：

- 手动处理窗口外历史；
- 阶段总结搜索、分页、编辑和删除；
- 骨架编辑、立即更新和完整重建；
- 最近一次真实角色请求的输入 Token 构成；
- 运行统计、最近一次裁剪记录和调试轨迹；
- 已脱敏的诊断报告。

## LLM 连接

默认复用 SillyTavern 当前主连接。后台总结会在酒馆公开相应设置钩子时临时关闭高成本思考、使用低推理和确定性采样，不修改用户预设。

也可以配置自定义 OpenAI 兼容接口。请求仍由 SillyTavern 的 Chat Completions 后端转发，浏览器不会直接把 API Key 发给第三方域名。自定义连接失败时可选择回退主连接。

自定义 Key 明文保存在当前 SillyTavern 用户的 `extensionSettings.story_echo` 中，以便刷新和多端同步。请使用限额、限权、可撤销的独立 Key。同页面其他扩展以及能读取酒馆用户设置的人可能看到它；Key 不会进入聊天元数据或诊断报告。

## 数据与一致性

每个聊天在 `chatMetadata.story_echo` 中独立保存：

- 阶段总结及其来源范围、来源哈希和更新时间；
- 全局骨架及其覆盖范围、来源哈希和失效状态；
- 运行统计、最近检查记录和有界调试轨迹。

编辑、删楼、Swipe、分支切换或聊天重命名时，插件会重新校验派生内容。来源不一致的阶段总结从第一个受影响范围开始截断；旧骨架标记为失效，在成功重建前不再注入。

从旧版本升级时，设置和聊天状态会只保留仍有用的上下文、阶段总结、骨架和诊断字段；旧的记忆、向量队列及 Embedding 配置会被移除。

## 开发

```bash
npm install
npm run typecheck
npm test
npm run build
npm run test:coverage
```

构建产物是 `dist/index.js` 和 `dist/index.js.map`。发布时需同步更新 `package.json`、`manifest.json`、源码常量及静态资源查询参数中的版本号。
