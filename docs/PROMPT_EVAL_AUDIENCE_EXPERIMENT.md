## 结论

**不采用新增听者示例，不替换生产 prompt。** 28 次生成均正常完成，但逐来源核查已触发预先冻结的停止条件：候选在两次关系稿中都重新加入“不得再独自行动”，新鲜对照两次均无此额外禁令；校园稿的听者扩写则是两组各一次，并未改善。没有继续调用 Judge、长链或补抽第三次，也没有修改来源、rubric 或验收条件。

## 请求前冻结

上一轮约定范围的泛化禁令消失，但“她说明”仍有一次被改成“她向悠说明”。用户同意继续用独立正反例处理。这次不向整个 scope 段落继续堆要求，而定义两个新实验组：

- **对照 `l2-binding-contract`**：完整生产 L2 prompt + 原来的两个事实绑定示例 + scope 段落中原样保留的约定范围句；移除抽象听者约束。
- **候选 `l2-binding-audience`**：与对照相同，仅再增加一个独立剧情示例块，示范未指定听者不补听者、旁白不变人物发言，以及后续明确告知时必须保留对象与知情更新。

两组都重新生成，不能把“删除抽象约束 + 新增示例”的整体差异直接当成示例收益。旧 `l2-binding-scope` 及保存结果不改，只作历史参考；生产 prompt 不替换。

新示例使用顾弦抄节目单、梁芷因琴弦断裂停演、乌澄不识乐谱的局部情节，不包含开发/回归案例人物与答案；明确标注不是当前剧情证据。示例后半段补充梁芷私下告知顾弦，而乌澄仍不知原因，防止候选通过删去所有明确听者来躲避错误。原先的两个示例、所有来源与 rubric、输出格式、8,000 Token 上限、L1/L3+ 均不变。

参考 [OpenAI Docs 提示词改进建议](https://developers.openai.com/api/docs/guides/prompting#refine-your-prompt)，将示例做成可读的紧凑列表并在发布前验证。官方建议通常将任务示例放 user；本轮为隔离变量，保持既有实验的 system 放置，不同时改变消息位置，也不声称这是唯一正确布局。示例有效与否以实际来源核对为准。

### 调用范围与验收门槛

1. 七例各生成对照/候选两次，共 **28 次**串行请求，顺序为 control-r1、candidate-r1、candidate-r2、control-r2。每组含全部七例，不挑选有利案例；固定 `deepseek-v4-flash`、temperature 0、非思考、纯文本、300,000ms 单次超时。路径先检查不存在，逐例保存；网络、空内容、截断或保存失败立即停止，不重试/补抽/切模型。
2. 以新生成对照为主要比较对象，核对 source/rubric 指纹相同。七例是已使用的合成回归场景，不再当未见留出集或真人专家金标准，不读取私人聊天。
3. 先逐来源复核：未指定听者是否被补全、旁白是否变发言；明确的证人口述、道歉对象、场内通知、私印展示/验看对象等是否被保留；并检查约定范围、关键支线、动机、条件、专名和新增断言。
4. 若听者扩写仍在重复样本中出现，或候选为避错而删掉关键明确告知/因果，或出现其他关键回退，不进入付费 Judge 与长链。本轮不根据输出修改示例再抽第三次。轻微措辞/拼写另列，不当作重大事件反转，也不抹掉。
5. 若主要目标在两次都改善且全七例无关键回退，复用现有校准做四个旧场景双向、两轮独立 GPT 盲评，先第一份生成最多 16 次；判定无跨轮分歧才考虑后续。之后才进入真实 L1 子总结的 L2 长链，不以票数自动发版。

## 逐来源核查

本节是执行代理对 `evals/cases.ts` / `evals/validation-cases.ts` 和全部 28 份生成正文的直接核查，不是独立 Judge 打分，也不是用户人工标注。

### 1. 关系：新增示例伴随明确回退

来源的旧约定是“不单独冒险”，新规则是“涉及家人威胁时也必须发送预设暗号”。新鲜对照两次都保留这两个范围，没有增加普遍禁止单独行动的条款。

候选两次却都在新规则后追加 **“不得再独自行动”**，把通报义务与高风险限制扩成一般行动禁令。候选 r1 还把未指定求助对象的“不得求助”缩窄为“禁止她向周砚求助”；r2 的“向任何人求助”不按同样的缩窄错误处理。其余核心威胁对象、营救、受伤、误解解除、试行搭档和等待幕后者落网再回答感情等仍保留，不能把此项描述成全部关系线丢失。

### 2. 校园：目标没有改善，其他扩写仍不稳定

- 来源只有“她说明拒绝源于价值观不合”，没有指明听者。对照 r2 与候选 r2 都写成 **“她向悠说明”**；另两份没有补听者。本次观察为对照 1/2、候选 1/2，不支持示例改善目标问题。
- 对照 r1 和候选 r2 都加入“同住”，但来源只明确私下亲密和留宿，没有共同居住的事实。
- 候选 r2 还写出“悠对千纱抱有超出‘家人’的感情，多次吃醋却始终否认”，把有限的吃醋/承认不舒服写成确定内心感情、重复发生及持续否认；“并未放在心上”和被误删的是“本地备份”也超出明确来源。
- 候选 r1 未明确保留千纱此前答应说明会结束后赶去观看的承诺，只保留最终迟到但赶上结尾。主要的诗织成长、脚伤恢复、云端副本、保管责任、寒假日期未定和见习送站仍在，属于具体承诺遗漏，而不是整条支线消失。
