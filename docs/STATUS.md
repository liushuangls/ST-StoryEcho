## 已知边界

- 首次生成阶段总结和骨架仍需要可用 LLM；
- 阶段总结条目为可审计数据，会随聊天长度线性增长；
- 世界书参考读取依赖 SillyTavern 公开接口或兼容模块；
- Token 卡片依赖 SillyTavern 保存的最近提示词明细；缺失分类计数时会明确显示估算；
- 临时聊天离开后由 SillyTavern 删除，其 StoryEcho 聊天元数据随聊天一起消失。
