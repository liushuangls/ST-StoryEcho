# L2 约定范围最小消融（2026-09-06）

## 结论

**不采用 `l2-contract-only`，也不能再把这句话称为已验证可独立获益的约束。** 28 次生成均正常结束，但候选两次都出现额外的“不得再独自行动”，本轮生产对照只出现一次；候选另有星盘状态遗漏、同居断言等回退。依请求前冻结的规则停止，实际调用 28 次生成、0 次 Judge、0 次长链、0 次重试。

保留生产 prompt、默认模型和版本，不提交推送。这否定的是本次最小候选的采用依据，不证明所有约定指令都无效，也不证明生产 prompt 没有问题。历史实验中看见的局部改善仍是历史样本结果，不能单独归因于这句话或当成跨样本稳定收益。

## 请求前冻结

上一轮添加听者示例后没有修复听者问题，还重新引入了泛化禁令。本轮只回答一个更窄的问题：此前有收益的约定范围句，脱离所有教学示例后能否独立改善生产 L2 的约定范围错误。

- 对照为未经更改的 `production`。
- 候选为 `l2-contract-only`，仅在生产 L2 system 末尾追加原样保留的 `L2_BINDING_CONTRACT_GUIDANCE`（小标题加一句约束，共 83 个 Unicode 码点），不包含任何事实绑定或听者示例。
- 原有 `l2-binding-contract` 及其他历史候选全部冻结，不改旧名字对应的 prompt。消息位置、来源、rubric、L1/L3+、默认模型、纯文本输出格式和接口层 8,000 Token 上限均不变。

唯一新增文本：

```text
约定范围
约定、承诺、许可与禁令优先沿用来源的完整关键语句，保留提出者、承担者、条件和适用范围；只保留来源已有的限制，不把提醒、通报义务或局部要求改写成额外禁令。
```

### 调用及判定边界

1. 固定七个已有 L2 场景，每组两次，共 28 次生成；顺序为 production-r1、candidate-r1、candidate-r2、production-r2。固定当前 `deepseek-v4-flash` 连接，temperature 0、显式关闭思考、300,000ms 超时、串行调用。每次结果即时保存，网络/空正文/截断/保存失败即停止，无自动重试、补抽或模型切换。
2. 使用新路径且请求前检查均不存在。所有来源与 rubric 指纹必须一致；这七例已经用于迭代，是合成回归集，不再声称未见留出集或用户专家金标准。
3. 主要目标：关系稿中泛化行动禁令是否在两次候选均消失，并且相对本轮生产对照有改善。只删掉约定或失去承担者/条件不算通过。
4. 同时逐来源检查全部场景的关键事实、因果、已明确的行为/回应、资源数量、所有权、许可和不确定性。与生产对照共同存在的老问题单独列出，不包装成无错误；候选出现新增关键回退，或目标没有稳定收益，则停止，不进入 Judge 或长链。本轮不现场改句子后抽第三次。
5. 若两次候选目标均改善且没有新增关键回退，可复用现有校准，让独立 `gpt-5.6-sol` 对第一份生成的四个原始 L2 场景做双向两轮 A/B，最多 16 次 Judge；若位置/跨轮判定不稳定或出现回退，停止。该比较只支持是否继续验证，不自动批准发布。本轮最多 44 次付费请求，不执行长链。

## 逐来源核查

以下是执行代理对全部 28 份正文与 `evals/cases.ts` / `evals/validation-cases.ts` 的直接比较，不是独立 Judge 或用户专家评分。

### 关系：主要目标失败

来源分别限定旧约定“任何高风险行动必须共同决定”/“不单独冒险”和新规则“涉及家人威胁时也必须发送预设暗号”。候选 r1/r2 都在新规则中加入“不得再独自行动”，生产 r1 没有、r2 有。因此不是两次候选均改善，且不能从历史生产样本反推本轮已经获益。

其他风险也保留记录：候选两份把妹妹“安全”威胁进一步写成“性命”相胁；候选 r2 又补“幕后者身份与动机尚未查明”，来源只说追查幕后者，还将等待“幕后者落网”概括为“幕后事件了结”。生产 r2 则把不得求助增写成“求助或声张”。不把某组的错误隐去，来制造另一组的优势。核心营救、违约、误解解除、试行合作与暂缓感情答复四份仍在，并非整条关系线丢失。

### 并行任务：候选一次漏掉整项持续状态

星盘来源明确：已修好但缺少校准，当前读数可能偏东两到五度。生产两份和候选 r2 均保留；**候选 r1 整项未提及**。这不是去掉重复句，而是少了一条仍影响后续行动的信息。

四份其余主要状态均保留：渡河牌已用并归还、银叶药尚未交付且月蚀剩一天、阿明左手触觉不可逆但可活动、蓝账簿原件再失、公会条件未满足、灰衣人的有限外貌线索和不得据此指认的要求。

### 校园：候选的居住断言与回应错配

- 来源只说明私下亲密与留宿，候选两份都明确写成“搬到京都后同居”；本轮生产两份没有同居断言。候选 r2 还将同居作为对外隐瞒的既定事实。
- 来源是接受咖啡邀请、暂未答应后来提出的正式约会。候选 r1 却将咖啡邀请也写成“没有当场答应”，把后一个行为的回应移给前一个；其余三份未出现此错配。
- 候选 r2 保留“悠感到不舒服”，但未明确保留他向千纱承认不舒服的行为；不把内心状态与实际表态视为同一信息。
- 两份生产均有确定的超出家人感情描述，候选 r1 也有“恋爱感情”；候选 r1 另补“千纱清楚”其不舒服的范围与“本地备份”。来源不能支持所有这些内心/知情/存储位置的扩展。本轮四份拒绝高濑的说明都没有另补具体听者，但这不是本候选的已证实独有收益。
- 四份仍保留诗织的成长、伤势恢复、学园祭、千纱此前观看承诺、云端副本补救、文件保管责任、寒假日期未定和见习送站，没有把整条配角线删除。

### 修仙：登记扩写两组各一次，不当成独有回退

候选 r1 写“登记上缴备案”，生产 r2 写“登记上交”；另两份只写登记。故此项为两组各一次，不说只有候选有问题，也不证明短句已经改善资源/义务边界。

概率与新增动机另列：生产 r1 把“重伤可能很高”写成“伤势可能极重”，候选 r1 写“重伤可能性极高”；生产 r2 新增“为应对险境”的突破原因。候选 r2 的重伤概率表述更贴近来源，但这一例的局部措辞改善不足以抵消主要目标及其他场景的失败。结丹后裂纹的因果措辞普遍强于来源的“裂纹未愈”，不将其单独计成重大反转。

四份仍保留上/下卷与口诀限制、丹药及符的消耗、担保物所有权与暂管、30 日退还条件、剑冢资格待复查、师尊生死及传音时间未明、信任未完全恢复等主要状态。

## 后续决定

停止这条“在原 prompt 后追加约束”的局部路线，不再在同七例上改同一句、追加示例或补抽到通过。此前的约定范围句、教学示例和这次最小候选均不能仅凭局部好例合入生产。

如继续，建议换成**仅本地的生成后来源核验实验**：保留本轮已生成的固定稿件，测一次有明确修订范围的核验能否纠正禁令扩写、同居断言、登记上交和星盘遗漏，同时不引入新事实或删掉正确情节；这属于不同的调用流程，尚未创建或执行，也不自动给插件增加第二次请求。是否接入生产应在观察纠错收益及额外耗时后另行决定。
