# L1 历史事件链组织：下游恢复对照

## 请求前冻结方案（2026-09-20）

目标是后续 LLM 能否正确利用总结，不评价人类可读性，也不以出现标题作为质量通过条件。

- Control：v0.21.20 的完整 L1 提示词，包含中性归档规则。
- Candidate：当前源码 L1，只替换历史事件链组织规则；长且跨实际阶段时使用少量事实性标题，短总结保持分段；条件与承诺留在事件链中，状态限定为本批结束时。
- 沿用两个脱敏合成场景：校园录音授权与保管、奇幻远征身份与资源。每例 32 条消息合并成一个 L1 批次，来源及世界书相同，不传入问答答案。每个版本各两轮，第二轮反转场景和版本顺序。
- 生成使用既有 DeepSeek V4 Flash 配置，阅读使用独立 GPT-5.6 Sol 配置；temperature 0，输出各限 3,000 Token。模型名是连接配置及接口自报，不作为真实身份认证。
- 每例先对原文做一次 8 题问答校验；全部答对后才生成总结。阅读器仅接收原样总结及问题，不拆句、不改排版，也不接收原文或正确答案。
- 总计最多 18 次串行调用：2 次原文读取、8 次总结生成、8 次总结读取。无自动重试，网络错误、空输出、截断、JSON/逐字引用错误时停止；已完成结果保留。
- 请求前在新的 `evals/results/history-structure-*` 目录写入完整计划、提示词、用例与哈希；请求逐条保存实际请求哈希、响应、自报模型/Token、时间及传输信息，不覆盖历史目录，不保存密钥或明文连接地址。

## 判定方式与边界

先统计下游问题的正确数，再人工核对引用是否完整支持所选答案，以及总结相对原文是否新增事实、颠倒因果、扩大授权/知情范围、升级承诺完成状态。引用存在不等于语义成立，自动选择题全对也不代表全文保真。

出现候选独有的关键事实错误，不因标题更多、文字更少或总分更高而接受。两版本都全对只说明本轮探针未测出差异，不宣称有提升。输出长度、Token 和延迟仅作成本诊断，不设置事后长度淘汰线。

本轮使用已有场景，不是未见留出集；末尾含状态复述，可能出现探针天花板效应。只验证 L1 单批恢复，不覆盖 L2+ 递归压缩、真实续写或用户实际 Gemini 连接。整体组织规则同时改变标题选择、事件链及时间边界，不能把结果单独归因于标题符号。

## 结果

**结论：未测出下游问答提升，且候选出现一处事实确定性扩大，本轮不通过，不建议发布当前组织规则。** 这不证明标题必然有害，也不能把单次错误确定归因于该规则；它说明目前没有足够证据接受这次修改。

18/18 次请求完成，全部 HTTP 200、`finish_reason=stop`，无空响应、截断、JSON 或逐字引用校验错误，无重试、请求时间区间无重叠。两个原文对照各答对 8/8；18 个客户端请求 ID 和响应 ID 均不同，10 个响应携带服务端请求 ID，且这 10 个 ID 各不相同。生成配置为 `deepseek-v4-flash`、响应自报 `deepseek-flash`；阅读配置和响应自报为 `gpt-5.6-sol`。

### 逐来源及引用复核

1. **候选远征第二轮扩大了确定程度。** 来源消息 9 写的是“岑月奉命追查被盗名单，而非已被证明是窃贼”，真正盗取者未知；候选写成“岑月奉命追查被盗名单，并非窃贼”。“尚未被证明有罪”不等于“已排除是窃贼”。旧版两轮和候选第一轮均保留“并非已被证明的窃贼”。问题出现在 `request-13.json`；阅读器在第 14 次请求中仍答对身份选择题，并原样引用了这个有问题的句子，说明现有题目未覆盖“是否已排除嫌疑”这条边界。不能以 8/8 为全文保真证明。
2. **期望的历史阶段标题没有稳定实现。** 候选校园第一轮出现五个独立粗体标题，但主要是“设备与录音归属”“感情与采访”等主题分类；校园第二轮变成段首主题引导语，两份远征候选都没有独立小标题。故不能把这次结果视为一个稳定执行的“有标题 vs 无标题”实验。
3. **事件与去重仍有波动。** 候选校园第一轮省略了林夏承认越权并道歉的过程，第二轮恢复；两版均存在段末待办/状态清单重复前文事实的情况。候选远征稿使用“截至本批结束”，明确了时间范围，但本轮问答没有测出因此新增的准确性收益。
4. 80 个答案（16 个原文、64 个总结）的引用均通过逐字存在性检查，已对照总结和原文复核。候选校园第二轮 `knowledge` 引用选取了早期知情状态和授权规则，未直接引用稿中后面的“陈梨……仍不知直播事故”；答案可由完整稿支持，但引用覆盖不够直接。这再次说明引用存在性不能替代语义检查。本轮保留原始自动分数，不事后改题或刷分。

### 局限与下一步

此处只有 16 道不同的选择题，两个版本各重复两轮，不是 64 道独立题。既有场景末尾状态复述明显，原文及两版总结均达到探针天花板；不能据此断言长上下文、开放式续写或 Gemini 上没有差别。本轮也没有跨摘要的后来状态覆盖测试。

建议暂时保留已发布 v0.21.20 的 L1 基线，不上线这次组织规则。若继续研究，应另建未参与调参的用例，增加“未被证明 vs 已排除”、局部事件顺序和后续状态覆盖的开放式探针；另做同一文本仅增删标题的对照，区分版式效果与事实取舍变化。不要根据本轮输出继续补一句限制再在同一批样本上追求满分。

本轮没有修改已冻结的生成提示词、用例或正确答案，没有回退本地候选源码，也没有提交或发布。测试工具与结果保留，是否撤回候选代码由后续决定。
