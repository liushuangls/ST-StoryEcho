# L2 重要表态保留最小候选实验

## 冻结方案（真实请求前）

本轮只检验一个假设：当来源明确记录人物作出影响关系、边界、承诺或后续行动的重要表态/回应时，L2 应保留“人物作出了这项表态/回应”这一剧情事件，不能只留下内心感受、最终标签或客观结果。

候选 `l2-statement-events` 只在生产 L2 system prompt 末尾追加一段通用要求；不改生产代码，不叠加此前的去重、证据边界、关系过程、来源措辞、事实绑定、约定范围或听者示例，不加入测试人物、剧情答案、固定字数或结构化输出要求。L1、L3+、来源、世界书、rubric、用户 prompt 和 8,000 Token 输出上限保持不变。

按照 [OpenAI 官方模型提示指南](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-5.5#prompting-best-practices) 对总结/改写任务“先说明必须保留的内容”和“从保持产品契约的最小 prompt 开始”的建议，本轮不再堆叠二次核验或自动纠错。该指南只是实验设计依据，候选是否有效仍以本项目输出的逐来源复核为准。

### 固定输入与调用

复用 `contract-only-production-r1.json` 与 `contract-only-production-r2.json` 中生产 prompt 的 7 个 L2 完整输出作为固定基线；两份基线均为 `deepseek-v4-flash`、temperature 0、非流式、每例 8,000 Token，prompt/evaluation 指纹逐例一致且没有截断。候选使用同一生成连接、同一 7 个场景，各独立生成两轮，共新增 14 次请求；顺序为候选 r1 后候选 r2，严格串行，不重试、不补抽。复用历史基线节省 14 次重复调用，但生产与候选并非同一时间交错采样，此限制必须保留。

固定场景：关系反转、十条并行剧情、校园群像、修仙资源，以及巡演、极地科考、城邦和谈三个验证题材。它们都已参与此前开发，不是未见留出集。

候选结果写入新的忽略路径：

- `evals/results/statement-events-candidate-r1.json`
- `evals/results/statement-events-candidate-r2.json`

若任一请求发生网络错误、空正文、截断或落盘失败，本实验停止，不用重跑替换失败证据。结果不进入 GitHub CI，不记录 Key 或连接地址。

### 冻结复核门槛

先逐条对照完整来源，不使用上一轮不稳定的错误定位器作为自动裁判，也不先看 A/B Judge 分数。

目标保留检查：

1. 校园两轮都应明确保留悠作出“承认不舒服”的表态，同时保留未告白和关系标签未变；只写他感到不舒服不算命中。
2. 关系反转两轮都应保留叶岚坦白感情，以及周砚没有接受/拒绝并把答复推迟到幕后者落网后的回应。
3. 巡演两轮都应保留唐梨澄清署名、裴渡承认删段改变因果并道歉、唐梨只恢复本场合作及后续删改需先征得同意。
4. 极地两轮都应保留罗音收回隐瞒指责并道歉，以及以后同时通知现场队员这一针对转发缺口的约定。
5. 和谈两轮都应保留沈微道歉、陆昭接受并恢复陪同、要求父亲调查先告知及沈微答应。
6. 并行剧情与修仙两轮都应保留来源已有的关键承诺、要求、承认和回应，且不能用最终状态完全替代其影响后续的行为。

副作用检查：不得把高风险共同决定扩成全面“不得独自行动”，不得把留宿/私人空间写成同居或共有公寓，不得把旁白中的私印证明边界写成温策或其他人物说过的话；不得新增听者、知情范围、所有权、信息来源、时间关系、任务完成阶段或更深心理定性。每例 rubric 的关键事实、因果链与未知边界不能因强调表态而退化。

只有 14 份候选全部通过来源复核、目标表态两轮稳定保留，且相对两份生产基线出现可归因的完整性改善而无事实回归，才进入现有双向 A/B Judge 和长链验证。若目标只是与生产持平、或任何一稿出现关键遗漏/新增事实，则不推广，不以篇幅更长或某个模糊总分替代来源门槛。

## 实测结果

**候选不通过，不进入 A/B Judge、长链或生产。** 14 次候选生成全部正常完成，目标表态均有保留，但两份生产基线在同一批检查上也都已保留，没有观察到候选带来的完整性增益。与此同时，两轮城邦和谈稿都把来源中的客观证明边界写成温策“指出”的人物发言，正好违反候选自己的“不要补写表达方式”要求；另有三处来源范围、因果或动机扩写。按冻结门槛，不能用“表态出现了”抵消这些事实问题。

候选两轮没有关键剧情整项遗漏，说明新增规则没有把目标事件压掉；但生产基线在相同来源上的 14 份对应检查也全部命中。这里只能说明两种 prompt 在这批输出都能保留这些表态，不能据此证明候选提高了发生概率。

### 来源边界与副作用

1. **城邦和谈 r1、r2：明确失败。** 来源写“温策验看后确认私印是真品，但私印不能证明陆峤目前生死或下落”，只明确温策确认真伪，后半句是客观叙述。两份候选都写成“温策……但指出私印不能证明……”，新增了人物作出该表态的事实。两份固定生产基线也有同一问题，因此候选没有修复已知薄弱点。
2. **关系反转 r2：范围与强度扩写。** 来源只写绑匪以妹妹“安全”威胁叶岚“不得求助”；候选改成以妹妹“性命”胁迫，并指定“不得向周砚求助”。前者加重威胁强度，后者把未指定的求助范围绑定到特定对象。r1 没有这两项扩写。
3. **校园 r1：新增因果连接。** 在备份事故及诗织接管最终版之后写“诗织由此成为街舞社正式成员”，会把正式入社与文件事故连成来源没有给出的因果；来源把正式成员状态放在演出完成后的最新状态中。r2 没有这一连接。
4. **修仙 r2：新增行动动机。** “为应对危机，宁昭……强行结丹”中的危机没有来源证据；来源只陈述服丹强行结丹及后果。r1 使用“为突破境界”，与结丹行为本身相符。
5. 和谈 r2 又把“藏着父亲私印”写成“私藏父亲的私印”，带有比来源更强的违规色彩。它不单独作为否决项，但与该稿新增发言一并保留为措辞风险。

候选相对固定基线也出现几项改善信号：没有重现生产 r2 的全面“不得再独自行动”，两轮都没有把登记扩成上交，校园两轮没有替悠确认“超出家人”的深层感情。但生产与候选不是交错采样，而且这些变化并非目标表态规则的稳定直接结果，不能只挑改善项归因给候选。

### 决定与下一步

保留 `l2-statement-events` 作为本地失败实验入口和可复现证据，不合入生产。没有调用不稳定的定位器，没有调用 A/B Judge，没有长链或重试请求；实际新增 **14 次生成、0 次 Judge**。

下一步不应继续在生产 prompt 后累加独立段落。更有信息量的做法是对生产 L2 的现有原则 1–2 做一次**等长或更短的整合改写**：把已有的“关键对话所确立的事实”和“关系变化过程”收束成同一条结果导向规则，同时明确“客观事实不能改成人物发言”。先以离线 prompt diff 和本轮七例做候选，不新增示例或调用后置核验；仍须保留独立的新题材留出集，避免继续只对这七个已知场景调参。
