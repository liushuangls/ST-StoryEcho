# 生成后来源核验实验（2026-09-07）

## 结论

**有局部纠错收益，但未达到接入生产的条件。** 28 次核验全部正常结束，12 份正文改变、16 份原样返回；明确的额外行动禁令和登记上交都被去掉，但同居断言只修完整一份，另一份只删了首次出现，后文仍保留；整项遗漏的星盘没有补回。模型“做过一次核验”不能当作稿件已经可靠。

本轮没有在已正确保留的关键剧情上发现新的重大错误或整项删除，但仍有未改掉的既有错误与遗漏，且样本很小、来源已参与迭代，因此不把这个观察扩展为真实长篇使用保证。不改生产 prompt、调用流程、模型配置或版本，不 commit/push。

## 请求前冻结

上一轮最小 prompt 消融没有稳定收益。本轮不再修改生产总结 prompt，而测试一种**仅用于本地评测**的不同流程：原稿已经固定，只加一次来源核验修订。它会多一次模型调用，尚未接入插件，也不意味着今后默认启用。

### 输入与模型

- 固定上一轮全部四份生成结果，每份七例，共 28 份稿件：`contract-only-production-r1.json`、`contract-only-candidate-r1.json`、`contract-only-candidate-r2.json`、`contract-only-production-r2.json`。不只挑有错误的稿件，保留巡演等未发现明显关键错误的稿件来检查误改。
- 每稿只修一次，按上述文件顺序、文件内部原有场景顺序串行运行，共 **28 次新增请求**；不重新生成原稿、补抽、重试、临场更改核验 prompt、切模型或调用 Judge/长链。
- 核验使用现有生成连接 `deepseek-v4-flash`，temperature 0、显式关闭思考、单次超时 300,000ms、接口上限 8,000 Token、正常文本输出。这里是同模型核验，不称作独立评审。Key 从环境读取，不能写入稿件或版本库。
- 请求前校验全部原稿：完整成功的仅生成结果、非空且未截断、L2、当前来源/rubric 与原请求 prompt 指纹一致、无重复 ID、总调用数不超过 28；新输出目录必须不存在，避免覆盖原结果。任何网络、空正文、截断或保存错误停止，不继续后面的请求。

### 核验模型可以看到什么

`evals/source-revision.ts` 中的 `SOURCE_REVISION_SYSTEM_PROMPT` 固定核验规则。user 只包含 JSON 编码的 `source` 和 `draft`：前者是原始剧情来源、世界书背景及来源元数据，后者是固定原稿。不发送 rubric、评分、案例 purpose/name、之前的 Judge 输出、手工错误清单或原生产/候选生成指令。资料中的指令仅作为数据，世界书不能证明剧情已发生。

模型须只做必要修订：纠正比来源更强、更具体或错误绑定的事实；补回影响后续的重要遗漏；保留原稿正确内容、必要因果、行为回应和有意义的已结束情节。没有问题时原样返回。只输出完整总结正文，不要求输出核验过程、评分或结构化 JSON。

沿用 [OpenAI Docs 关于修改提示词后做评测的建议](https://developers.openai.com/api/docs/guides/prompting#refine-your-prompt)。指令给出编辑职责，但并不保证模型真的完成了核验；最后仍按原始来源检查修订结果，不能采用模型自报的“已核验”标签。

### 记录与判定

1. 保留每稿原文、原文哈希、原生成请求哈希、父结果哈希、来源/rubric 哈希、核验协议和请求哈希、修订正文、字符数、结束原因、usage 与网络耗时。`changed` 只表示正文不同，`generationSucceeded` 只表示请求成功，`qualityEvaluated` 始终为 false。
2. 按来源逐一标出**已修复、仍残留、新引入和被误删**，不能用总字数降低或改动多证明质量改善。对照对象是同一份固定原稿，不是重新抽取的生产稿。
3. 主要观察对象预先固定：额外行动禁令、留宿变同居、登记变上交、星盘状态遗漏、邀请/回应错配、未指定听者变人物发言，以及与这些错误相邻的正确因果、约定和状态是否还在。强度、性别、内心等次要扩写另列，不与重大事实反转混算。
4. 只有主要问题在所有含错输入里都被修正，且没有新增关键错误或遗漏，才支持进入更独立的后续验证；不因修掉部分错误就直接改变生产流程。对未改动的正确稿件也核对是否仍正确。七例已用于多轮迭代，不是未见留出集或用户人工金标准。
5. 本轮结束后报告请求总量、网络附加耗时和输入/输出体积。先不使用按价格推算的费用，也不把网络耗时混入本地性能结论。无论结果如何，本轮不自动发版、commit 或 push。

## 复现

在本地加载已配置环境变量后运行。输出目录必须是新路径，每次复现另选后缀；原始结果不覆盖：

```sh
STORY_ECHO_EVAL_REVISION_INPUTS='["evals/results/contract-only-production-r1.json","evals/results/contract-only-candidate-r1.json","evals/results/contract-only-candidate-r2.json","evals/results/contract-only-production-r2.json"]' \
STORY_ECHO_EVAL_REVISION_OUTPUT_DIR=evals/results/source-revision-20260907 \
STORY_ECHO_EVAL_TIMEOUT_MS=300000 \
npm run eval:revise
```

该工具是显式本地命令，不加入 GitHub CI、`npm run check` 或发布构建。原稿和新结果均应位于 Git 忽略目录。
